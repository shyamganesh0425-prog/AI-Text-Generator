# AI Text Generator 🤖

My first Generative AI project built using Python and Google's Gemini API.

## 📌 About the Project
This project is a simple AI Text Generator that allows users to enter questions or prompts and receive AI-generated responses using Google's Gemini model.

## 🚀 Features
- Generate AI responses from user prompts.
- Ask multiple questions in a single session.
- Interactive command-line interface.
- Secure API key input using Python's `getpass`.

## 🛠️ Technologies Used
- Python
- Google Gemini API
- Google Gen AI SDK
- Jupyter Notebook

## 📦 Installation

Install the required package:

```bash
pip install google-genai
```

## ▶️ How to Run
1. Clone this repository.
2. Open the Jupyter Notebook.
3. Run the notebook cells.
4. Enter your Gemini API key when prompted.
5. Start asking questions!

## 🔐 Security
The Gemini API key is entered securely using `getpass`. Never share your API key or upload it to GitHub.
